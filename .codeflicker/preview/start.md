# 个人主页 启动指南

## 项目概述
这是一个纯静态HTML个人主页，包含index.html和style.css，无需构建或启动服务器。

## 预览方式

### 快速启动

**方式一：直接打开**
```bash
open index.html
```

**方式二：使用Live Server（如已安装）**
- 在VSCode中右键index.html，选择"Open with Live Server"
- 或使用其他本地服务器工具

**启动后访问**：直接在浏览器中查看index.html

```yaml
subProjectPath: .
command: open index.html
cwd: .
port: null
previewUrl: file:///Users/zhouchao/Personal/zhouchao310.github.io/index.html
description: 纯静态个人主页，包含个人简介、新闻动态、论文列表、奖项和联系方式
```
